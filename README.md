# Teste Técnico – Vaga de Suporte

## Objetivo
Avaliar a capacidade do candidato em reproduzir conteúdo e formatação utilizando HTML e CSS, com atenção a detalhes e fidelidade visual.

---

## Instruções

1. Crie uma página HTML simples utilizando o conteúdo do arquivo **Boi.docx**  
   - O texto deve ser reproduzido fielmente
   - Mantenha títulos, parágrafos e links conforme o documento

2. Insira a imagem abaixo no **cabeçalho da notícia**:
   https://www.scotconsultoria.com.br/bancoImagensUP/220622_ROTA_1_Boitel_Chaparral-SP_BM-3859.jpg

3. Estilização:
   - Links devem ser exibidos na cor **verde**
   - A formatação (fonte, espaçamentos e alinhamentos) deve seguir, o máximo possível, o padrão apresentado no Word
   - Utilize CSS externo ou interno

4. Responsividade:
   - A página deve se adaptar corretamente a diferentes tamanhos de tela (desktop e mobile)

---

## O que esperamos
- HTML
- CSS
- Layout responsivo

---

## Observações
- É permitido usar qualquer editor de código
- É permitido consultar a internet
- O foco do teste é a fidelidade visual e organização do código

---

## Entrega

Envie sua solução em um arquivo **.zip** para **at@scotconsultoria.com.br** em até **10 dias corridos** após o recebimento do teste.

- **Assunto do e-mail:** `Teste Suporte – Seu Nome`
- **Nome do arquivo:** `teste-suporte-seu-nome.zip`

> ⚠️ **Não** faça fork nem Pull Request deste repositório.

### O .zip deve conter
- Todo o código-fonte do projeto
- Um arquivo **`README.md` na raiz** com o passo a passo para executar o projeto, incluindo:
  - Pré-requisitos e versões utilizadas
  - Instalação de dependências
  - Configuração necessária
  - Comando(s) para executar (ex.: `abrir o index.html no navegador`)

### Não inclua no .zip
- Pastas de dependências (`node_modules`, `vendor`, `venv`, `.venv`, `__pycache__`)
- Arquivos com senhas reais (`.env`); envie um `.env.example` no lugar

> Se o arquivo passar de 20 MB, envie um link de download (Google Drive, WeTransfer etc.).
